# Дополнения для Claude Code

Общие правила проекта находятся в `AGENTS.md`. Не копируй их сюда и не создавай противоречащие им версии тех же правил.

- Для повторяющихся процедур портирования, TC4R-интеграции и проверки используй Skills в `.claude/skills/`; сначала прочитай соответствующий `SKILL.md`.
- Для Java и ресурсов применяются path-scoped правила из `.claude/rules/`. Не загружай и не пересказывай их для задач, которые не затрагивают соответствующие пути.
- Подробная архитектура, TC4R API и сборка описаны в `docs/development/`. Читай только документ, относящийся к текущей задаче.
- Текущее состояние и статус проверок бери из исходников, CI и `docs/verification.md`, а не из старых сообщений или предположений.
