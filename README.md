# Thaumic Horizons: Reforged

An unofficial port of [Thaumic Horizons](https://github.com/GTNewHorizons/ThaumicHorizons) (MC 1.7.10, by Kentington; maintained by GTNewHorizons) for [Thaumcraft 4: Reforged](https://github.com/notlikethiss/thaumcraft-4-reforged) on modern Minecraft.

Requires **Thaumcraft 4: Reforged** as a hard dependency.

- Minecraft 26.3 / NeoForge / Java 25 (`main`), backports planned for `mc/26.1.2` and `mc/1.21.1`.
- The port keeps the original gameplay 1:1, except for documented deviations — most notably the player-invisibility infusion is reimplemented without the original sync/render bug (see `CLAUDE.md`).

The original 1.7.10 sources are preserved in `reference/1.7.10/` and on the `legacy/1.7.10-gtnh` branch. The legacy license notice of the 1.7.10 fork is kept below.
